# BioStudy

A lightweight biology learning and note organization app.

## v0.1
- Course management
- Chapter management
- Notes with tags
- Note search
- Review queue
- Dashboard statistics
- Local browser storage
- Responsive layout
- No build system or dependencies

## Roadmap
1. Markdown note editor and file import
2. Course/chapter progress tracking
3. Flashcards and active recall
4. Spaced repetition
5. Quiz generator
6. Biology diagrams and image attachments
7. Export/import backup
8. Optional cloud sync and authentication

This is a static site and can be deployed with GitHub Pages from the main branch and root folder.
